# [CySecNotes 🛡️](https://cy-sec-notes.vercel.app/)

🌐 **網站：** [https://cy-sec-notes.vercel.app/](https://cy-sec-notes.vercel.app/)

課堂的傳統筆記內容多而分散，溫習時難以快速找到重點，所以我把每一課的教材整理成「雙語應考學習指南」與「考前精讀 Cheatsheet」，再用這個網站集中起來隨時溫習。

- 📚 **主要用於自用溫習**：搭車、等上堂、考試前，隨時打開就能複習
- 🤝 **順帶分享**：如果覺得有幫助，歡迎參考使用；網站會跟隨課堂進度持續更新

## 免責聲明

本網站內容根據課堂教材整理，可能存在錯漏或過時資訊，**請以官方課堂教材及導師講解為準**。網站僅供個人學習參考之用，不構成任何專業或學術建議。
